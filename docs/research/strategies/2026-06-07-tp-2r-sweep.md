# Pure ≥2R take-profit sweep — 18-point grid, all rejected

## Hypothesis & market rationale
Distinct from [[2026-06-03-full-exit-model]] (no partials/BE — a *pure single target* at
2R/2.5R/3R keeps live == backtest): maybe a bigger 1:2+ payoff beats the 1R target even at
a lower win rate.

## Sources
`docs/TP_2R_SWEEP.md`; reproducible spec `config/optimize/tp2r.yaml` (seed 0, grid).

## Relation to prior library work
Second attempt to extend reward-per-trade on [[2026-06-02-session-breakout-er]] after the
scaled exit was rejected; differentiation was live-parity (single broker TP). It was real —
and still failed, more sharply.

## Strategy spec
Grid 18 = `target_r_multiples` {[2.0],[2.5],[3.0]} × `atr_mult_sl` {0.8…1.8 step 0.2},
base HEAD v4, `move_be_after_r` null. Run via `scripts/optimize.py`, judged at
trial_count = 40.

## Implementation notes
No code change (existing levers). Real EURUSD M15, 2024-01 → 2026-05, $100k.

## Backtest results
| | INCUMBENT v4 (1R) | best ≥2R: tp 2.5 / sl 1.4 |
|---|---|---|
| in-sample expectancy | +0.294R | +0.312R |
| win rate | **73.2%** | 42.8% |
| PF / Sharpe | **1.99 / 3.36** | 1.47 / 1.75 |
| DSR @ 40 trials | **0.997 PASS** | 0.766 FAIL |
| stitched OOS | +0.28R | +0.40R (the trap) |
| **lockbox** | **+0.303R, PF 2.03 PASS** | **+0.074R, PF 1.08 FAIL** |

Leaderboard: every combo PF 1.34–1.51, Sharpe 1.14–1.91, DSR 0.38–0.84; win rate 36–48%.

## Verdict
REJECT all 18; no proposal. HEAD v4 unchanged. Cumulative trial count now **40**.

## Lessons
- The ≥2R question is now answered **twice** (scaled and pure). Family + failure mode:
  *exit-model extensions on SessionBreakoutER trade away the win-rate edge and die on
  held-out data*. Do not re-test ≥2R targets on this strategy without a fundamentally new
  mechanism (e.g. regime-conditional targets backed by new evidence).
- Stitched-OOS expectancy can look better while the lockbox collapses — the lockbox is the
  point.
- Process: long sweeps need chunked, checkpointed runs in the sandbox.

## Next steps
Reward-extension ideas belong on trend/momentum candidates. For the incumbent, pursue
entry-side filters (HTF bias, TOD/DOW, vol-of-vol) instead of exit-side changes.
